# ADR 011 — Renderizado 3D realista de árboles

## Contexto
El laboratorio requiere una vista forestal realista, no una nube de puntos ni pilares extruidos. El navegador puede no disponer de GPU dedicada.

## Opciones
1. Three.js/react-three-fiber con mallas procedurales.
2. deck.gl MeshLayer.
3. Puntos/cilindros abstractos.

## Decisión
Se adopta Three.js mediante `@react-three/fiber` y `@react-three/drei`. Cada árbol combina un cilindro de baja poligonización para el tronco y un cono para la copa. La altura y copa se derivan de atributos sintéticos inspirados en RH98/biomasa. El prototipo usa 700 árboles para mantener una carga razonable; una evolución posterior puede migrar a `InstancedMesh` real con LOD por distancia.

## Consecuencias
La representación cumple la semántica visual de árbol individual y permite cámara orbital, iluminación y sombreado. No pretende reconstruir especies reales. La limitación de 700 árboles es deliberada para hardware modesto. Los colores codifican riesgo: sano, intermedio y alto.
