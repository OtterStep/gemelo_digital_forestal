# ADR 010 — Contrato de API React/Python

## Contexto
El laboratorio React necesita consumir el mejor modelo, diccionario de datos, simulación y reportes sin duplicar la lógica de negocio.

## Decisión
FastAPI expone:
- `GET /modelo/mejor`: nombre, métricas, versión y fecha.
- `GET /diccionario`: rangos y unidades de controles.
- `POST /simular`: recibe escenario y devuelve línea base, escenario, deltas, serie temporal y geometría de árboles.
- `POST /reporte`: recibe resultado trazable y devuelve metadatos del reporte.

Todos los resultados incluyen `source_version`. El front incorpora un fallback `synthetic_test` para que la demostración funcione sin backend.

## Consecuencias
La simulación se mantiene en Python cuando el backend está disponible; el fallback permite desarrollo offline. La interfaz nunca entrena modelos.
